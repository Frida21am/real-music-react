# Real Music — учебный каталог музыкальных инструментов

Фронтенд интернет-магазина на Next.js, React и TypeScript. Проект показывает каталог, категории и подкатегории, поиск, фильтры по цене, сортировку, карточку товара, избранное и корзину. Состояние избранного и корзины хранится в браузере.

Данные товаров загружаются из [публичного WooCommerce Store API](https://developer.woocommerce.com/docs/apis/store-api/). В проекте нет ключей WooCommerce и функций оформления заказа или оплаты. Доступность каталога зависит от `wp.real-music.store`.

## Запуск

```bash
npm ci
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Для сборки используйте `npm run build`.

## Как устроен проект

- `src/app` — страницы и серверный маршрут `/api/catalog`, который обращается к публичному каталогу.
- `src/api` — запросы и преобразование данных товаров для интерфейса.
- `src/hooks` — загрузка каталога и состояние интерфейса.
- `src/components` — карточки товаров, фильтры, корзина и страницы.

Проект сделан в учебных целях; изображения и сведения о товарах принадлежат их правообладателям.
